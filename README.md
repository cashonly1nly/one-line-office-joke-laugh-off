One original one-line office joke about office life, written to get a laugh out of coworkers: a judge model reads the jokes two at a time and keeps the funnier one. This program writes that one line deterministically to `/output/entry.txt` — no input, no network, no randomness.

## Run it

```sh
node main.ts
```
